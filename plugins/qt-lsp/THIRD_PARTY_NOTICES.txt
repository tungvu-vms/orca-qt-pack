Qt Code Intelligence for Orca bundles the following third-party components.

Monaco Editor 0.52.2 (editor/assets/*.js, *.css, codicon font)
  Copyright (c) Microsoft Corporation. MIT License.
  https://github.com/microsoft/monaco-editor

vscode-textmate 9.2.0 and vscode-oniguruma 2.0.1 (bundled into editor/assets, onig.wasm inlined)
  Copyright (c) Microsoft Corporation. MIT License.
  Oniguruma: Copyright (c) 2002-2021 K.Kosako. BSD-2-Clause.

TextMate grammars and themes (inlined into editor/assets):
  - C, C++, C++ embedded macro grammars, C/C++ language configuration, Python language
    configuration, Dark+ / Light+ color themes: VS Code built-in extensions, MIT License,
    Copyright (c) Microsoft Corporation.
  - MagicPython / MagicRegExp grammars: Copyright (c) 2015-present MagicStack Inc. MIT License.
  - QML grammar: seanwu1105/vscode-qt-for-python, MIT License (via stablyai/orca-plugins).
  - JavaScript grammar: microsoft/vscode (from microsoft/TypeScript-TmLanguage), MIT License.

The language servers are NOT bundled; the plugin starts them from the user's machine:
  - basedpyright (MIT), installed with npm
  - qmlls (part of Qt, LGPL-3.0 / commercial)
  - clangd (part of LLVM, Apache-2.0 WITH LLVM-exception), e.g. shipped with Qt Creator
